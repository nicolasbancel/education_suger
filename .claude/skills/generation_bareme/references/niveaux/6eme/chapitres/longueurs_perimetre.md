# Chapitre 6ème — Longueurs et périmètre

Barème des exercices de longueurs / périmètre. Déclencheurs : "longueurs", "périmètre",
"côtés", "calculer le périmètre".

Source : interro 6.

## Déduire des longueurs à partir de la nature d'un triangle

- Utiliser le fait que les côtés sont égaux (triangle équilatéral → 3 côtés égaux ; isocèle → 2 côtés égaux) : −0,5 si ce fait n'est pas mobilisé pour conclure.
- Valeur correcte donnée sans justification : crédit partiel ≈ `0,25/1`.

## Périmètre

- Périmètre = **somme des longueurs des côtés**. −0,5 si la définition (somme des côtés) n'est pas appliquée correctement.
- **Oubli de l'unité** (cm) dans le résultat : −0,5.
- −0,25 si erreur de calcul mais démarche correcte.
