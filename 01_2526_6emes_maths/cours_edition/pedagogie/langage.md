## Tournures et registre

### Em dash (—) interdit dans tout texte poussé

**Règle** : ne jamais utiliser d'em dash `—` dans le contenu poussé dans les Docs de cours.

**Pourquoi** : ce n'est pas un signe de ponctuation usuel en français scolaire (collège), il est typiquement utilisé en anglais ou dans la prose adulte. Il déstabilise les élèves de 6ème et n'a pas d'équivalent oral clair.

**Remplacements** selon le sens :
- **Causal / explicatif** ("X — Y") → deux-points (`:`) ou point-virgule (`;`)
- **Incise** ("X — précision — Y") → parenthèses `(...)` ou virgules
- **Liste / énumération** → puce ou virgule
- **Pause** → point ou virgule

**Cas d'application** : tout contenu poussé via les scripts `gdoc.*`. À vérifier au moment de la rédaction (Étape 3 du skill) ET au moment du challenge (Étape 3 bis).

### Consignes d'exercice : verbes à l'infinitif

**Règle** : dans une liste d'instructions adressées à l'élève au sein d'un énoncé d'exercice, **utiliser l'infinitif** (et non l'impératif).

**Pourquoi** : style standard des énoncés de mathématiques au collège. L'impératif personnalise trop ("toi tu fais ça") ; l'infinitif est neutre et factuel.

**Exemple** (chap 6, section Graphique linéaire) :
- ❌ "nomme les deux axes" / "place les points" / "relie les points"
- ✅ "Nommer les deux axes" / "Placer les points" / "Relier les points"

**Verbes courants — toujours à l'infinitif** (ajouté 2026-05-21) : "Montrer que…", "Démontrer que…", "Calculer…", "Nommer…", "Placer…", "Relier…", "Compléter…", "Construire…". Ne jamais écrire la forme impérative ("calcule", "montre que", "construis").

**Cas d'application** : tous les bullets ou listes de consignes qui suivent une phrase d'introduction du type "À toi de jouer. ... :" ou équivalent. Capitaliser la première lettre (début de phrase).

L'introduction qui annonce la liste (ex : "À toi de jouer.") peut elle rester en impératif ou interpellation.

## Adresse aux élèves (tu / vous / impersonnel)

### 2026-05-21 — Ne jamais tutoyer les élèves

**Règle** : ne pas employer le tutoiement ("tu") pour s'adresser aux élèves dans le contenu des cours. Préférer :
- le **"nous" inclusif** (enseignant + classe associés dans une même démarche) : "nous allons apprendre", "nous utilisons"
- le **"on" impersonnel** : "on peut programmer sans compte", "on inverse deux étapes"
- les **possessifs impersonnels** : "son adresse email" plutôt que "ton adresse email"

**Pourquoi** : registre de classe. Le "nous" associe l'enseignant et les élèves dans une démarche commune ; le "tu" est trop familier pour un support écrit de cours.

**Exemple** :
- ❌ "tu vas apprendre à programmer", "tu utilises des machines tous les jours"
- ✅ "nous allons apprendre à programmer", "nous utilisons des machines tous les jours"

**Cas d'application** : tout contenu poussé dans les Docs de cours (paragraphes, intros, transitions). Les consignes d'exercice, elles, suivent la règle de l'infinitif (voir section ci-dessous).
